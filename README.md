ABSTRACT
We present a comprehensive atlas of human esophageal development, integrating single-cell transcriptomics and spatial profiling to identify stage-specific epithelial and mesenchymal populations. Using this framework, we developed a scalable 3D esophagoid model that recapitulates key features of esophageal architecture, including basal-to-luminal stratification and stromal organization. Functional studies reveal that WNT2B regulates epithelial progenitor dynamics. Together, these findings define the esophagoid as a physiologically relevant platform for studying epithelial-stromal interactions and modeling esophageal development and disease.
